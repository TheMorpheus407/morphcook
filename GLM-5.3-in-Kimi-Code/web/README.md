# web/ — runnable HTML/JS prototype (reference)

Open `index.html` in any browser. No build step, no dependencies beyond
Google Fonts.

This is a **visual reference**, not the product codebase (see SPEC.md):
- newspaper masthead + dateline
- striped placeholder plates with caption bands
- polaroid grid with alternating tilt
- diet-variant switching on the dish page (blocked combos gray out with a note)
- vegan/halal profile filters flipping the whole feed

The Flutter app in `../app/` is the real implementation; when visuals drift,
`../design/` is the source of truth.
